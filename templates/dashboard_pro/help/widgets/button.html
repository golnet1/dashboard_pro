Виджеты

Кнопка

Кнопка

button↑ к списку виджетов

Большая цветная кнопка, выполняющая действие по нажатию.

Все поля

Ниже — полный список полей настройки виджета: каждое поле, его ключ в файле виджета, тип и значение по умолчанию. Ключ нужен, если вы правите код виджета вручную или собираете свой виджет в конструкторе.

Основное params
ПолеТипПо умолчаниюОписание
Название
title		text—Заголовок карточки. Если пусто, виджет подставляет своё название.
Иконка
icon		icon_pickerfas fa-playКласс иконки Font Awesome, например fas fa-lightbulb.
Тип кнопки
button_type		selectscriptДействие кнопки: переключение панели, вызов метода объекта или запуск сценария.
Объект (метод)
method_obj		method_object—Объект, метод которого вызывается кнопкой. В паре с полем «Метод». Показывается: пока Тип кнопки = method; в паре с method.
Метод
method		method—Имя метода объекта, который вызывается кнопкой. В паре с полем «Объект». Показывается: пока Тип кнопки = method; в паре с объектом выше.
Имя сценария
script		script—Имя сценария, который запускает виджет. Показывается: пока Тип кнопки = script.
Параметр
param		text—Значение, передаваемое сценарию в качестве параметра. Показывается: пока Тип кнопки = script,method.
Панель
panel		panel_select—Панель, на которую переключается кнопка. Показывается: пока Тип кнопки = panel.
Признак доступности
object_alive		object—Объект, по которому проверяется «живость» виджета: если он не отвечает, карточка гаснет и перестаёт откликаться.
Свойство (доступность)
property_alive		property—Свойство объекта «живости», по которому виджет понимает, что связь жива.
Таймаут (сек)
alive_timeout		number—Сколько секунд ждать ответа, прежде чем считать объект недоступным. По умолчанию 3.
Цвет
color		color#1565c0Цвет фона карточки. Применяется, когда выбран режим «Свой цвет».
