Потоковое видео

Потоковое видео

stream↑ к списку виджетов

Просмотр потокового видео с камер и других источников, включая ONVIF и RTSP.

Как работает

Поток показывается через серверный мост hls_bridge (ffmpeg), который пережимает источник в живой HLS и держит соединение при обрывах камеры. Для go2rtc используется встроенный HLS сервера go2rtc.

  • URL — прямая ссылка: http(s) на HLS (.m3u8), или rtsp:// (транскодируется на сервере).
  • Свойство — URL потока берётся из значения объекта.
  • go2rtc — хост (host:port) и камера из списка go2rtc; подключается напрямую.
  • ONVIF — полный поток RTSP камеры через сервис ONVIF: URL сервиса, логин и пароль. Режим «Показ»: Полный экран (весь кадр), Камера 1 / Камера 2 (одна из половин кадра для панорамных камер).

Дополнительно — снижение нагрузки

Настройки применяются при транскодировании через hls_bridge (ONVIF и RTSP через «URL»/«Свойство»).

НастройкаОписание
Качество (разрешение)Оригинал / 720p / 480p / 360p — пониженное разрешение снижает нагрузку на процессор сервера.
Ограничение кадров/сКак в источнике / 15 / 10 / 5 FPS — чем меньше, тем ниже нагрузка.

Для межсетевого экрана: мост работает на сервере, где установлен модуль; поток доставляется HLS-сегментами по HTTP.
