Служебный виджет для разработки и проверки.

Все поля

Виджет не объявляет полей настроек: в его карточке настройки есть только общие для всех виджетов параметры — размеры, фон, заголовок и иконка. Собственных полей нет.

title
title		text—Заголовок карточки. Пусто — подставляется название виджета.
icon
icon		icon_pickerfas fa-flaskКласс иконки Font Awesome, например fas fa-cube.
color
color		color—Цвет фона карточки.
height
height		number100Высота карточки в пикселях.
