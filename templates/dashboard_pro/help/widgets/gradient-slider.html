Ползунок с градиентной шкалой вместо сплошного цвета трека.

Все поля

Ниже — полный список полей настройки виджета: каждое поле, его ключ в файле виджета, тип и значение по умолчанию. Ключ нужен, если вы правите код виджета вручную или собираете свой виджет в конструкторе.

Основное params
ПолеТипПо умолчаниюОписание
Название
title		text—Заголовок карточки. Если пусто, виджет подставляет своё название.
Тип иконки
icon_type		selecticonОткуда берётся иконка: из набора Font Awesome, из свойства объекта или по ссылке на картинку. От этой настройки зависит, какие из трёх полей ниже показываются.
Иконка
icon		icon_pickerfas fa-fill-dripКласс иконки Font Awesome, например fas fa-lightbulb. Показывается: пока Тип иконки = icon.
Объект (иконка)
icon_object		object—Объект, свойство которого даёт иконку. Показывается, когда выбран тип «Свойство». Показывается: пока Тип иконки = property.
Свойство (иконка)
icon_property		property—Свойство объекта, значение которого используется как иконка. Показывается: пока Тип иконки = property.
URL иконки
icon_url		text—Адрес картинки, которая показывается как иконка: https://… либо путь внутри модуля. Показывается: пока Тип иконки = url.
Объект
object		object—Объект Majordomo, из которого виджет читает значение или в который его записывает.
Свойство
property		propertylevelСвойство объекта, значение которого показывает виджет. Список свойств появляется после выбора объекта; пока объект не выбран, поле остаётся пустым и показывает «по умолчанию».
Минимум
min		number0Минимум шкалы.
Максимум
max		number100Максимум шкалы.
Шаг
step		number1Шаг шкалы. Пусто или any — дробные значения разрешены.
Цвета colors

В этой вкладке нет обычных полей.

Дополнительно advanced
ПолеТипПо умолчаниюОписание
Фон виджета
bg_mode		select—Откуда берётся фон карточки: тема виджета, картинка, свой цвет или цвет из свойства объекта.
Цвет
color		color—Цвет фона карточки. Применяется, когда выбран режим «Свой цвет». Показывается: пока Фон виджета = color.
URL изображения
bg_image		text—Адрес фоновой картинки. Показывается, когда выбран режим «Картинка». Показывается: пока Фон виджета = image.
Объект (цвет)
bg_object		object—Объект, свойство которого задаёт цвет фона. Показывается, когда выбран режим «Цвет из свойства». Показывается: пока Фон виджета = property.
Свойство (цвет)
bg_property		property—Свойство объекта, значение которого используется как цвет фона. Показывается: пока Фон виджета = property.
Признак доступности
object_alive		object—Объект, по которому проверяется «живость» виджета: если он не отвечает, карточка гаснет и перестаёт откликаться.
Свойство (доступность)
property_alive		property—Свойство объекта «живости», по которому виджет понимает, что связь жива.
Таймаут (сек)
alive_timeout		number—Сколько секунд ждать ответа, прежде чем считать объект недоступным. По умолчанию 3.
