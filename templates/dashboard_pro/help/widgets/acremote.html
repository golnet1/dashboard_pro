Пульт кондиционера

Пульт кондиционера

acremote↑ к списку виджетов

Управление кондиционером: режим, температура, вентилятор, качание.

Как работает

Пульт показывает текущий режим и температуру. Кнопки (питание, режим, температура ТЕМП+/−, вентилятор, качание) меняют состояние кондиционера, и при каждом нажатии отправляется всё состояние одним JSON-объектом выбранным способом (коды отдельных кнопок не используются).

Основные настройки

НастройкаОписание
Способ отправкиУстановить свойство / Команда / Сценарий.
Объект отправки / СвойствоКуда записывается код.
Префикс командыПрефикс при способе «Команда».
СценарийСценарий, получающий состояние кондиционера.

Какие данные отправляются

Пульт не использует коды кнопок: при каждом нажатии отправляется полное состояние кондиционера одним JSON-объектом.

ПолеЗначенияОписание
on0 или 1Включён / выключен.
modeauto, cool, heat, dry, fanРежим: авто, охлаждение, обогрев, осушение, вентиляция.
temp16…32Целевая температура, °C.
swing0 или 1Качание заслонки.
fan0…4Вентилятор: 0 — авто, 1–4 — скорость.

Пример: {"on":1,"mode":"cool","temp":24,"swing":0,"fan":2}. При «Установить свойство» JSON записывается в свойство целиком; при «Команда» — с префиксом; при «Сценарий» — JSON разбирается и передаётся сценарию как параметры.
