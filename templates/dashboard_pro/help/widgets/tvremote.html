Пульт ТВ

Пульт ТВ

tvremote↑ к списку виджетов

Экранный пульт телевизора.

Как работает

Каждая кнопка соответствует коду из «Коды кнопок». Способ отправки определяет, как код доставляется: записью в свойство, командой с префиксом, сценарием с кодом, либо прямым управлением ТВ по IP (порт по умолчанию 1925).

Основные настройки

НастройкаОписание
Способ отправкиУстановить свойство / Команда / ТВ по IP / Сценарий.
Объект отправки / СвойствоКуда записывается код (при «Установить свойство»).
Префикс командыПрефикс перед кодом (при «Команда»), например IR_.
IP телевизора / ПортУправление ТВ по IP (при «ТВ по IP»).
СценарийИмя сценария, запускаемого с кодом (при «Сценарий»).
Коды кнопок (JSON)Словарь кодов: {"power":"TV_PWR","vol+":"VOL_UP","vol-":"VOL_DOWN"}. Если поле пустое или кнопка не задана — используются команды из таблицы ниже.
