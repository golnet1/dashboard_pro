Виджеты

Диммер

Диммер

dimmer↑ к списку виджетов

Управление яркостью: тумблер вкл/выкл + ползунок уровня (по умолчанию 0–100).

Как работает

Отслеживает состояние (объект/свойство) и уровень яркости. Тумблер включает/выключает (методы перекл/вкл/выкл), ползунок устанавливает уровень в свойство уровня.

Основные настройки

НастройкаОписание
Объект / СвойствоСостояние (вкл/выкл).
Объект (перекл) / Метод переключенияМетод переключения состояния.
Объект (вкл) / Метод включенияМетод включения.
Объект (выкл) / Метод выключенияМетод выключения.
Уровень объекта / Свойство уровняОбъект и свойство, в которое записывается уровень яркости.
Минимум / Максимум / ШагДиапазон и шаг уровня яркости (по умолчанию 0–100, шаг 1).
