Виджеты

Музыкальный проигрыватель

Музыкальный проигрыватель

musicplayer↑ к списку виджетов

Проигрыватель медиа из папки модуля: плейлист, управление воспроизведением, громкость, спектр в реальном времени и цветомузыка. Кнопка + в шапке добавляет файл из папки или по ссылке.

Как работает

Плейлист. Начальный список берётся из поля Плейлист по умолчанию (JSON-массив вида [{"src":"cms/sounds/a.mp3","title":"A"}]). Если заданы Объект плейлиста и Свойство плейлиста, проигрыватель читает плейлист оттуда и сохраняет туда же каждую правку (с задержкой ~0,7 с). Если объект не задан, изменения плейлиста запоминаются в поле «Плейлист по умолчанию». Список можно записать и простым текстом — каждая строка или запятая становятся отдельным треком.

Файлы. Поле Папка с файлами задаёт каталог медиа (по умолчанию cms/sounds). Кнопка + открывает список файлов этой папки: отметьте нужные галочками и нажмите «Добавить выбранные». Ниже есть поле для URL — так добавляется файл или интернет-поток, которых нет в папке.

Воспроизведение. Плей/пауза, предыдущий и следующий трек, перемешивание и повтор (кнопка цикла — выкл / один трек / все треки). Ползунок громкости Ш выставляет громкость, клик по полосе прогресса перематывает. Название трека выводится из имени файла, пока оно не задано явно в плейлисте.

Спектр и цветомузыка. Спектр считается из звука через Web Audio API, колонки раскрашиваются по списку Полосы частот. Кнопка-лампочка в шапке включает цветомузыку: спектр пишется в связанные свойства объекта в виде уровней 0–255 или сигналов вкл/выкл. Устройство не пишется из браузера напрямую — свойство объекта меняется, а про приём на порт заботится серверная часть (например модуль megad). Подробности — во вкладке «Цветомузыка» ниже.

Цветомузыка light

Вкладка связывает спектр с «лампой»: портами объекта (простые лампы и диммеры), RGB-лентами и адресными светодиодными лентами. Устройство выбирается полем Тип устройства — от него зависит, какие поля ниже показываются.

ПолеТипПо умолчаниюОписание
Тип устройства
dev_type		selectportsЧто пишет виджет: «Лампы на портах», «RGB-лампы и ленты» или «AI-ленты (адресные, WS2811 / WS2812)».
Количество каналов
port_ch		select3Сколько каналов (ламп) задействовано: от 3 до 7. Спектр режется на столько же полос по логарифмической шкале частот. Показывается: пока Тип устройства = ports.
Канал 1 … Канал 3
object_p1/property_p1 … object_p3/property_p3		object/property—Объект и свойство для каждого канала: то, во что записывается уровень/состояние. Показывается: пока Тип устройства = ports.
Канал 4 … Канал 7
object_p4/property_p4 … object_p7/property_p7		object/property—Дополнительные каналы. Каждый следующий показывается, когда «Количество каналов» больше: канал 4 — от 4, канал 5 — от 5 и так далее. Показывается: пока Тип устройства = ports и «Количество каналов» позволяет.
Режим
port_mode		selectfreq«Каналы разбиты по частотам» — каждый канал держит свою полосу спектра; «Бегущая волна (по ритму)» — яркая точка-волна бежит по каналам в такт музыке. Показывается: пока Тип устройства = ports.
Что писать в канал
port_out		selectonoffФормат значения: «Яркость 0-255 (диммеры)» — пишется уровень как есть; «Вкл/выкл 0/1 (простые лампы)» — уровень сравнивается с порогом и пишется 1 или 0. Показывается: пока Тип устройства = ports.
Уровень включения лампы
cm_on_level		number90Порог уровня, начиная с которого простая лампа (режим «Вкл/выкл 0/1») зажигается: 1, если яркость полосы ≥ порога, иначе 0. Диапазон 0–255, шаг 5. Чем выше порог — тем реже лампа вспыхивает: при пороге 90 лампа загорается примерно на ярком звуке, при 5 — почти всегда. Значения вне 0–255 не используются — берётся значение по умолчанию 90. Показывается: пока Тип устройства = ports и «Что писать в канал» = onoff.
Как писать свет
wr_mode		selecthexФормат записи цвета: строка #rrggbb в одно свойство или три значения R/G/B в три свойства. Показывается: пока Тип устройства = rgb или ic.
Объект / Свойство (hex)
object_hex/property_hex		object/property—Куда пишется цвет в формате #rrggbb. Показывается: пока Как писать свет = hex.
Объект R / G / B
object_r/property_r, object_g/…, object_b/…		object/property—Три свойства для составляющих цвета, когда выбран формат RGB. Показывается: пока Как писать свет = rgb.
Эффект
ic_mode		selectcmДля адресных лент: «Цветомузыка (по частотам)», «Бегущая волна (по ритму музыки)», «Бегущая волна с разными оттенками», «Разнобой в ритме». Показывается: пока Тип устройства = ic.
При окончании звучания
end_action		selectoffЧто сделать по окончании трека: всё выключать / всё включать / оставлять последний цвет. Показывается: пока Тип устройства = rgb.

«Цветомузыка» — это только запись свойств объекта: виджет не общается с контроллером напрямую. Свойства должно принимать то звено, которое реально пишет на порт (обычно megad-модуль по событию изменения связанного свойства).
