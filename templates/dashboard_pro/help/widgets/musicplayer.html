Виджеты

Музыкальный проигрыватель

Музыкальный проигрыватель

musicplayer↑ к списку виджетов

Проигрыватель медиа из папки модуля: плейлист, управление воспроизведением, громкость, спектр в реальном времени и цветомузыка. Кнопка + в шапке добавляет файл из папки или по ссылке.

Как работает

Плейлист. Начальный список берётся из поля Плейлист по умолчанию (JSON-массив вида [{"src":"cms/sounds/a.mp3","title":"A"}]). Если заданы Объект плейлиста и Свойство плейлиста, проигрыватель читает плейлист оттуда и сохраняет туда же каждую правку (с задержкой ~0,7 с). Если объект не задан, изменения плейлиста запоминаются в поле «Плейлист по умолчанию». Список можно записать и простым текстом — каждая строка или запятая становятся отдельным треком.

Файлы. Поле Папка с файлами задаёт каталог медиа (по умолчанию cms/sounds). Кнопка + открывает список файлов этой папки: отметьте нужные галочками и нажмите «Добавить выбранные». Ниже есть поле для URL — так добавляется файл или интернет-поток, которых нет в папке.

Воспроизведение. Плей/пауза, предыдущий и следующий трек, перемешивание и повтор (кнопка цикла — выкл / один трек / все треки). Ползунок громкости выставляет громкость, клик по полосе прогресса перематывает. Когда перемешивание или повтор включены, их кнопки подсвечиваются зелёным. Название трека выводится из имени файла, пока оно не задано явно в плейлисте. Для обычного файла центральная кнопка — плей/пауза, а для интернет-потока (трансляции) — «Стоп»: поток не перематывается, и после остановки он начинается заново.

Эквалайзер. Кнопка с ползунками в шапке открывает эквалайзер из 8 полос (60, 130, 230, 500, 910, 3,6К, 8К, 14К Гц), каждая — от −12 до +12 дБ. Готовые настройки: Плоский, Рок, Поп, Ретро, Техно, Джаз, Классика. Кнопка «Своя» запоминает текущий набор ползунков как собственную настройку и возвращается к ней при повторном нажатии; если менять ползунки, когда выбрана «Своя», своя настройка обновляется. При выборе другого пресета подсветка «Своя» снимается, и ручные правки до нажатия «Своя» не сохраняются. Настройки эквалайзера хранятся в браузере.

Спектр и цветомузыка. Спектр считается из звука через Web Audio API, колонки раскрашиваются по списку Полосы частот. Кнопка-лампочка в шапке включает цветомузыку (по умолчанию она выключена); её подсказка называет действие — «включить» или «выключить». Когда цветомузыка включена, вместо столбцов спектра в карточке показывается то, что уходит на устройство: кружки-лампы (от 3 до 8, по числу каналов), цветная заливка для RGB или полоса светодиодов для адресной ленты. Рядом с лампочкой появляется кнопка смены режима/эффекта — её иконка меняется вместе с настройкой, а всплывающая подсказка называет текущий режим. Спектр пишется в связанные свойства объекта в виде уровней 0–255 или сигналов вкл/выкл. Для любого типа устройства при включении цветомузыки виджет запускает на сервере фоновый движок cm_engine.php, который пишет свойства сам, и останавливает его при выключении или паузе; браузер только посылает команды «старт/стоп». Про приём на порт заботится серверная часть (например модуль megad). Подробности — во вкладке «Цветомузыка» ниже.

При окончании звучания
end_action		selectoffЧто сделать, когда звук кончился: всё выключать / всё включать / оставлять последний цвет. Срабатывает в конце плейлиста и по кнопке «Стоп»; пауза всегда гасит свет. Показывается: пока Тип устройства = rgb или megad.

Свет для любого типа устройства пишет не браузер, а фоновый серверный движок cm_engine.php: панель в момент play/stop посылает ему одну команду «старт/стоп», а дальше он сам крутит кадры и пишет свойства — поэтому вкладку можно закрыть, движок продолжит работать. Он останавливается при паузе, выключении цветомузыки и остановке плеера. У него нет доступа к звуку, поэтому рисует он синтетический узор во времени, а не по спектру трека: для одного и того же трека картинка одинакова на любом устройстве. Всё, что делает браузер, — превью в карточке и цвет по частотам («Цвет по частотам»), тот по-прежнему пишется из вкладки.

«Цветомузыка» — это только запись свойств объекта: виджет не общается с контроллером напрямую. Свойства должно принимать то звено, которое реально пишет на порт (обычно megad-модуль по событию изменения связанного свойства). Кадр цветомузыки отправляется одним запросом, а при открытом websocket-канале — через него, поэтому на каждый канал не создаётся отдельное обращение к серверу.

Тип «MegaD (адресные ленты)» пишет кадр целиком в одно свойство: строка из N троек байт RRGGBB (N — «Число пикселей»), например для трёх пикселей ff000000ff000000ff без пробелов. Дальше это значение должно уходить на контроллер в параметре ws (например /sec/?pt=35&ws=<значение>) — как правило, это делает связанное свойство megad-модуля, которое перешлёт его на порт ленты.
