Виджеты

Робот-пылесос

Робот-пылесос

vacuum↑ к списку виджетов

Статус уборки, заряд батареи, ошибка и набор дополнительных показателей с кнопками управления.

Как работает

Виджет читает три основных свойства: статус, заряд и ошибку, а также любое число дополнительных метрик. Метрика появляется на панели, только если у неё задано свойство и объект (свой или «Объект отправки»). Заряд показывается горизонтальной полоской с процентами: значения 0…1 автоматически переводятся в проценты. Если статус совпадает со списком «Уборка», главная кнопка становится «Пауза», иначе — «Старт». Точка у статуса и строка ошибки подсвечиваются отдельно. Коды кнопок и метрики задаются обычными полями на отдельных закладках «Команды» и «Показатели» — вручную редактировать JSON не нужно.

Опрос идёт раз в 5 секунд (настраивается полем «Период обновления»). Время последнего обновления показывается внизу карточки, если включён чекбокс «Показывать время обновления» в «Дополнительно».

Команды vc_commands

Каждая строка — одна команда. В первой подстроке идут «Ключ», «Код», «Подпись» и кнопка выбора иконки (там же стрелки перемещения и удаление), во второй — «Объект» и «Свойство», оба выбираются из списков. Ключи start и pause управляют главной кнопкой, остальные строки выводятся сеткой в порядке списка. Подпись вида vc_* переводится; можно вписать и свой текст. При способе «Метод» код пишется как Объект/Метод.

Показатели vc_metrics

Каждая строка — один дополнительный показатель: объект и свойство выбираются из списков, рядом поля подписи, иконки и суффикса. Пустой объект означает «Объект отправки» из основных настроек. Строка без заданного свойства не показывается на панели и не опрашивается — так расход воды и дополнительные щётки появятся только после привязки их свойств. Строки можно добавлять, удалять и перемещать стрелками. Подписи выводятся полностью и переносятся на следующую строку, если не влезают.

Все эти строки уже заполнены по умолчанию на закладке «Команды»: можно поменять код любой кнопки или добавить свою. Если ключа в списке нет — используется код по умолчанию из таблицы.

Пара «Объект» и «Свойство» в строке команды превращает кнопку в переключатель: оба значения выбираются из списков, объект можно оставить пустым — тогда используется «Объект отправки» из основных настроек. В «Коде» через запятую перечисляются уровни от низкого к высокому в формате значение|что возвращает устройство|подпись. Первая часть — код, который записывается в свойство; вторая — то, что устройство сообщает в ответ (число или слово); третья — подпись уровня. Две последние части необязательны. Каждое нажатие берёт следующий уровень, а после последнего возвращается к первому. Текущий уровень перечитывается из свойства перед каждым нажатием, поэтому цикл всегда продолжается с того места, где устройство находится сейчас, в том числе после перезагрузки страницы. Уровни задаются только в настройках виджета — никаких таблиц соответствий внутри кода нет, поэтому виджет подходит для любой модели робота-пылесоса. Кнопка выводится в общей сетке вместе с остальными и показывает текущий уровень.

Пример: 0|Silent|vc_val_silent,1|Standard|vc_val_standard,2|Medium|vc_val_medium,3|Turbo|vc_val_turbo для мощности и 1|Low|vc_val_low,2|Medium|vc_val_medium,3|High|vc_val_high для воды. Это лишь пример: для своего робота укажите свои коды и значения. Если устройство возвращает слово, укажите его во второй части — совпадение будет найдено и после перезагрузки страницы. Подпись вида vc_* переводится через языковой файл, любой другой текст показывается как есть.

Способы отправки

РежимЧто делает
Свойство propertyЗаписывает код в свойство выбранного объекта (setProperty).
Команда commandВыполняет системную команду: префикс + код.
Метод methodВызывает метод вида Объект/Метод; код должен содержать оба компонента.
Сценарий scriptЗапускает сценарий; код передаётся в параметре key.

Дополнительные показатели

Список задаётся на закладке «Показатели». По умолчанию заполнены одиннадцать строк: режим, мощность всасывания, площадь, время, основная щётка, боковые щётки, расход воды, уровень воды, пылесборник, фильтр и комната. Метрика выводится, только если у строки указано свойство и есть объект (свой или объект отправки). У каждой строки есть поля:

ПолеОписание
objectОбъект отображаемого свойства. Пусто — «Объект отправки».
propertyСвойство выбирается из списка выбранного объекта.
labelПодпись. Ключ вида vc_* переводится на язык интерфейса, остальной текст показывается как есть.
iconИконка Font Awesome, выбирается кнопкой в строке, например fas fa-wind.
suffixСуффикс значения, например % или м².

Строки можно добавлять, удалять и менять местами стрелками — редактировать JSON вручную не требуется.

Каждая метрика показывается отдельной карточкой: крупное значение сверху, полностью выведенная подпись под ним. Если свойство метрики совпадает со «Свойством» одной из кнопок, виджет берёт подпись уровня из настроек этой кнопки — таблица соответствий для конкретной модели не требуется. Для свойств clean_time, clean_area и clean_times есть удобное форматирование (часы и минуты, разряды чисел); для остальных значений выводится то, что вернуло устройство, плюс заданный суффикс.
