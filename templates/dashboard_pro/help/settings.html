Настройки

Раздел доступен администраторам: меню пользователя в правом верхнем углу → Настройки. Изменения сохраняются автоматически; отдельной кнопки сохранения нет. Кнопка сохранения есть в шапке дашборда, но она относится к режиму правки. Вверху каждой страницы настроек есть стрелка назад — вернуться к дашборду.

Карточки расположены в три колонки. Слева наверху — «Название дашборда», «Панель по умолчанию», «Системные», «Настройки виджетов»; в средней колонке — «Внешний вид»; в правой — «Раскладка», «Инструменты», «Экспорт/импорт панелей», «Статистика».

Название дашборда

Заголовок панели в шапке и боковом меню. Если поле пустое, подставляется «Dashboard Pro».

Панель по умолчанию

Панель, которая открывается при запуске. Значение «— начальная —» открывает домашний экран со списком панелей. Записи-страницы по адресу в списке нет: открыть их как панель нельзя, только кликом по меню.

Аудит и очистка настроек

Окно открывается кнопкой «Очистка». Сначала выполняется поиск (статус «Поиск…»), затем показывается отчёт. Если проблем нет, выводится «Проблемных настроек не найдено».

Сообщения о проблемах выводятся сверху с предупреждающим значком. Дальше два раздела со списками, у каждой позиции свой переключатель:

  • Виджеты с некорректными настройками — для каждого виджета указаны причина, имя панели и идентификатор; такие позиции отмечены по умолчанию.
  • Неиспользуемые типы виджетов — файлы определений, которые не встречаются ни на одной панели; по умолчанию не отмечены.

Кнопки внизу: «Удалить выбранные» — удаляет только отмеченные позиции; «Закрыть» — выход без изменений. На месте «Удалить выбранные» может появиться кнопка «Восстановить панель» — она не про очистку, а про починку: сервер пытается собрать обрезанный или испорченный список панелей, и если данные разбираются, показывает сообщение «Настройки восстановлены, отрезано лишнего: N симв.». Если спасти нечего, сообщение будет другим: «Данные повреждены необратимо и сброшены. Восстановите панели через Wizard или Импорт» — тогда панели придётся собрать заново.

Очистка — не кнопка «удалить всё», а точечная работа по списку: снимите переключатели с лишних строк, если не хотите их удалять.

Экспорт/импорт панелей

Две кнопки карточки: Экспорт и Импорт.

Экспорт открывает окно с тремя режимами — выбор показывается списком с кружком выбора:

РежимЧто делает
ПользователиКопирует все настройки в Объект выбранного пользователя. Список пользователей подгружается при выборе режима; если у пользователя Объект не пустой, модуль предупреждает о перезаписи и запрашивает подтверждение. Файл не скачивается.
ВсеСкачивает файл dashboard_pro_export.json со всеми панелями и настройками.
ПанелиСкачивает файл dashboard_pro_export_<имя>.json с содержимым выбранной панели. Если выбрана группа, в файл попадает и всё, что внутри неё. Без выбора панели экспорт не выполняется.

Кнопки окна экспорта: «Экспорт» и «Закрыть».

Импорт открывает выбор файла (только .json). Если в файле есть массив панелей, он полностью заменяет текущий список панелей, а настройки из того же файла переносятся поверх текущих. Сделайте экспорт «Все» заранее: импорт не дополняет, а заменяет.

Формат обмена — JSON. Не редактируйте файл вручную: неизвестные поля и битый JSON приведут к ошибке при импорте.

Статистика

Количество панелей (limit 100), общее количество виджетов (limit 10000) и объём трафика WebSocket: отправка и приём.

Настройка заголовка (отдельный раздел)

Не входит в «Настройки»: меню пользователя (правый верхний угол) → Настройка заголовка. Шапка собирается из элементов, каждый можно убрать или поменять местами перетаскиванием. Кнопки списка: Добавить элемент, Очистить и По умолчанию (вернуть стандартный набор). У каждого пункта можно выбрать, показывать его «только иконкой», «только надписью» или «иконку и надпись».

Часы, индикаторы и режим редактирования — не параметры внешнего вида, а элементы шапки: их наличие задаётся здесь, в «Настройке заголовка».

Элементы, которые спрашивают значения

«Ссылка», «Значение объекта» и «Выбор панели» при добавлении сразу открывают свой диалог. Пока значения не выбраны, элемент в шапку не попадает: кнопка Сохранить неактивна, а Отмена закрывает диалог, не оставляя в шапке ничего.

ЭлементЧто обязательно выбрать
СсылкаАдрес. Без него кнопка «Сохранить» неактивна.
Значение объектаОбъект и его свойство. Без обоих «Сохранить» неактивна.
Выбор панелиПанель из списка. Пока панель не выбрана, «Сохранить» неактивна.

Название у ссылки необязательное: если его не вводить, в шапке и в подсказке показывается сам адрес. Уже добавленный элемент открывается тем же диалогом — карандаш в его строке, — и там «Отмена» оставляет прежние значения.
