Панели

Записи бокового меню бывают трёх видов: экран с виджетами, группа и страница по адресу. Экран с виджетами по традиции тоже называют панелью.

Добавление панели

  1. Включите режим редактирования (кнопка-карандаш в шапке, справа).
  2. В нижней части меню нажмите «Добавить панель».
  3. Укажите название панели (оно появится в меню и заголовке).
  4. Выберите тип записи: панель, группа или страница по адресу (подробнее ниже).
  5. Панель будет добавлена, и вы сможете размещать на ней виджеты.

Типы панелей

ТипОписание
Обычная панельСтандартный экран с виджетами.
ГруппаОбъединяет несколько панелей в выпадающий список. Группа сама по себе не содержит виджетов — в неё помещаются панели-дочерние элементы.
Страница по адресуЗапись без виджетов: по клику открывает указанный адрес в основной области под шапкой. Браузер остаётся на дашборде, страница занимает область целиком и прокручивается внутри неё. Выход — клик по любой панели в меню.

Чтобы сделать запись частью группы, откройте её свойства и выберите родительскую группу. В боковом меню такие записи появляются внутри раскрывающегося пункта группы.

Виджеты нельзя положить ни в группу, ни в страницу по адресу. Если в панели уже есть виджеты, сменить её тип на эти два нельзя — сначала уберите или перенесите виджеты.

В списке «Панель по умолчанию» в настройках страницы по адресу нет: открыть её как обычную панель нельзя, только кликом по меню.

Основная панель

Панель, которая открывается при запуске. Задаётся в Настройки → Панель по умолчанию (выбор из списка) либо значением «— начальная —», если открывать домашний экран со списком панелей.

Логотип в боковом меню открывает домашний экран со всеми панелями — это отдельное действие, оно не зависит от выбора основной панели.

Управление панелями

  • Переименование и свойства: в режиме редактирования нажмите карандаш у записи в боковом меню (на главном экране — карандаш на карточке).
  • Изменение порядка: в окне редактирования записи при помощи кнопок «Вверх» и «Вниз».
  • Удаление: в окне редактирования — удаление удалит и все её виджеты.
  • Скрытие в меню и на начальном экране: флажки «Скрыть в навигаторе» и «Скрыть на начальной странице» в свойствах записи.

Структура бокового меню

  • Логотип (вверху) — домашний экран со всеми панелями.
  • Список панелей — переход между экранами.
  • Группы — раскрываются по нажатию, внутри них дочерние записи.
  • Кнопка «Добавить панель» (внизу, в режиме редактирования) — новая запись меню.
  • Кнопка редактирования — карандаш в шапке, справа.

Лимиты

Поддерживается до 100 панелей, до 10000 виджетов суммарно.
