Панели

Записи бокового меню бывают трёх видов: экран с виджетами, группа и страница по адресу. Экран с виджетами по традиции тоже называют панелью.

Режим правки

В шапке справа есть кнопка с карандашом — «Режим правки». Она нужна для всех операций со списком меню. После включения карандаш превращается в кнопку «Сохранить» (значок дискеты), а рядом появляется вторая кнопка — «Добавить виджет». Чтобы вернуться в обычный режим, нажмите «Сохранить».

Это не то же самое, что «Режим редактирования» из «Настройки заголовка»: там кнопка только включает и выключает режим правки, здесь — переключает его и сохраняет.

Добавление панели

  1. Включите «Режим правки» (кнопка с карандашом в шапке, справа).
  2. В нижней части бокового меню нажмите «Добавить панель».
  3. Укажите «Название» — оно появится в меню и заголовке.
  4. При необходимости выберите «Тип иконки»: Icon (шрифтовая иконка), Property (значение свойства объекта) или URL image (картинка по адресу).
  5. Выберите «Тип панели»: Панель Dashboard, Группа или Страница по адресу (подробнее ниже).
  6. Нажмите «Добавить».
  7. Панель будет добавлена, и вы сможете размещать на ней виджеты.

Название обязательно: без него кнопка «Добавить» ничего не делает. У внутренней записи есть служебный идентификатор, он не виден в меню, поэтому одинаковые названия у разных записей допустимы — ориентируйтесь по иконке и группе.

Типы панелей

ТипОписание
Панель DashboardСтандартный экран с виджетами. В списке «Панель по умолчанию» называется «Начальная панель».
ГруппаОбъединяет несколько панелей. Группа сама по себе не содержит виджетов — в неё помещаются панели-дочерние элементы.
Страница по адресуЗапись без виджетов: по клику открывает указанный адрес в основной области под шапкой. Браузер остаётся на дашборде, страница занимает область целиком и прокручивается внутри неё. Выход — клик по любой панели в меню.

Для типа «Страница по адресу» появляется поле «Адрес страницы» с примером вида https://example.com/page.

Чтобы сделать запись частью группы, откройте её свойства и в поле «Группа» выберите родительскую группу (или «Начальная панель», чтобы оставить в корне меню). В боковом меню такие записи появляются внутри пункта группы.

Виджеты нельзя положить ни в группу, ни в страницу по адресу. Если в панели уже есть виджеты, сменить её тип на эти два нельзя — сначала уберите или перенесите виджеты.

В списке «Панель по умолчанию» в настройках страницы по адресу нет: открыть её как обычную панель нельзя, только кликом по меню.

Свойства записи (окно «Изменить панель»)

Окно свойств открывается карандашем у записи и состоит из двух вкладок — «Основное» и «Дополнительно». Кнопки внизу: «Вверх», «Вниз», «Отменить», «Удалить» и «Сохранить».

Основная панель

Панель, которая открывается при запуске. Задаётся в Настройки → Панель по умолчанию (выбор из списка) либо значением «— начальная —», если открывать домашний экран со списком панелей.

Логотип в боковом меню открывает домашний экран со всеми панелями — это отдельное действие, оно не зависит от выбора основной панели.

Управление панелями

  • Переименование и свойства: в режиме правки нажмите карандаш у записи в боковом меню (на главном экране — карандаш на карточке). Подсказка кнопки — «Редактировать панель».
  • Изменение порядка: кнопки «Вверх» и «Вниз» в окне свойств. Они недоступны на первой и последней позиции и меняют общий порядок записей в сохранённом файле, а не только вид в меню.
  • Удаление из окна свойств: кнопка «Удалить» в окне свойств удаляет запись вместе со всеми её виджетами и сразу сохраняет изменения — подтверждения не спрашивается.
  • Удаление с главного экрана: кнопка с корзиной на карточке панели; перед удалением спрашивает подтверждение «Удалить панель <название>?».
  • Скрытие в меню и на начальном экране: переключатели «Скрыть в навигаторе» и «Скрыть на начальной странице» на вкладке «Основное» окна свойств.

Структура бокового меню

  • Логотип и название (вверху) — домашний экран со всеми панелями.
  • Список записей — переход между экранами. Записи, у которых включён «Скрыть в навигаторе», в меню не видны.
  • Группа раскрывается нажатием на саму строку группы: у неё есть стрелка-шеврон. Внутри показываются только панели и страницы по адресу — вложить группу в группу нельзя, для групп поле «Группа» всегда «Начальная панель».
  • Карандаш у записи появляется при наведении и доступен только в режиме правки.
  • Кнопка «Добавить панель» внизу меню — только в режиме правки.
  • Кнопка навигатора в шапке (☰) на узком экране (до 768 px) открывает и закрывает меню поверх страницы, на широком — сворачивает меню до значков. Состояние запоминается в браузере.

Главный экран

Экран со списком панелей открывается кликом по логотипу или значением «— начальная —» в настройке «Панель по умолчанию». На нём карточками показываются группы и записи верхнего уровня, у которых не включён переключатель «Скрыть на начальной странице».

Карточка группы открывает список её содержимого; если содержимое пустое, выводится сообщение «В группе нет панелей». В режиме правки у каждой карточки есть карандаш и корзина.

Счётчики и ограничения

В карточке «Статистика» настроек показывается количество панелей и суммарное количество виджетов с подписями «(limit 100)» и «(limit 10000)». Это справочные значения: модуль показывает их, но не блокирует сохранение, если панелей или виджетов больше.

Реальное ограничение есть в «Настройке заголовка»: у индикаторов статуса максимум 10 штук (3 системных и 7 своих), при его достижении добавление отключается с подсказкой «Максимум 10 индикаторов (3 системных + 7 своих)».
