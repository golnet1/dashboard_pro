Редактор виджетов

Редактор виджетов (меню пользователя → «Редактор виджетов») позволяет управлять списком типов виджетов, доступных в панели: устанавливать новые, отключать ненужные и удалять.

Кнопка «Конструктор»

В строке каждого виджета есть кнопка Конструктор — она открывает визуальный конструктор и подставляет в него выбранный виджет: его название, разметку, вкладки настроек и код.

Кнопка в строке виджетаНазначение
КонструкторВизуальная правка виджета: внешний вид, панели настроек, код. Подробно — в разделе Конструктор.
ЭкспортСобрать ZIP (JSON + JS) для переноса на другую установку.
Отключить / ВключитьСкрыть тип из списка добавления или вернуть его.
УдалитьУдалить тип виджета. Используемые на панелях виджеты удалить нельзя.

Установка нового типа из архива делается кнопкой Добавить виджет в шапке списка, а не кнопкой «Конструктор». Чтобы доработать уже установленный виджет — нажимайте «Конструктор».

Возможности редактора

  • Список установленных виджетов — все типы, доступные для добавления на панели.
  • Конструктор — визуальная правка любого установленного виджета и создание нового.
  • Установка нового виджета — загрузка из ZIP-архива (JSON + JS), например виджета, скачанного с сайта модуля/сообщества.
  • Экспорт — упаковка виджета в ZIP (JSON + JS) для переноса на другую установку или передачи автору.
  • Удаление — удаление типа виджета. Виджеты, уже использующиеся на панелях, удалить нельзя — сначала уберите их с панелей.
  • Отключение — тип виджета можно скрыть из списка добавления, не удаляя.

Что такое файл виджета

Каждый тип виджета — это JS-файл в папке js/widgets/ модуля. В нём описаны: поля настройки (вкладки), логика отрисовки и взаимодействия с объектами. Редактор даёт возможность управлять этими файлами прямо из интерфейса, без доступа к файловой системе сервера.

Структура ZIP-файла виджета:

  • .json — описание виджета (имя, версия, поля, вкладки).
  • .js — код виджета (рендер, обработка действий).

Добавление собственного виджета

Самый простой способ — не писать файл вручную, а собрать виджет в конструкторе и выгрузить его в ZIP.

  1. Откройте Редактор виджетов и нажмите Конструктор, в поле Виджет выберите «— новый виджет —».
  2. Соберите внешний вид, панели настроек и код — см. раздел Конструктор.
  3. Сохраните виджет, затем выгрузите его кнопкой Экспорт.

Если виджет уже подготовлен вручную:

  1. Подготовьте JSON-описание и JS-код виджета (по образцу существующих в js/widgets/).
  2. Упакуйте оба файла в ZIP-архив.
  3. В редакторе нажмите «Добавить виджет» и выберите архив.
  4. После успешной установки тип появится в списке и станет доступен при добавлении на панель.

При ошибке установки (неверный архив, повреждённые файлы, уже установленный виджет) будет показано соответствующее сообщение.

Использование виджета, созданного вручную

Если вы добавили JS-файл напрямую в js/widgets/ на сервере, он автоматически подхватится панелью. Кнопка «Обновить список» в редакторе обновит перечень установленных типов.
