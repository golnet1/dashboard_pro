Виджеты

Виджет — это элемент панели, который отображает данные или управляет объектом. Виджеты размещаются на панелях и настраиваются в режиме редактирования.

Добавление виджета

  1. Включите режим редактирования (карандаш внизу бокового меню).
  2. Нажмите кнопку «+» на нужной панели (или «Добавить виджет»).
  3. Выберите тип виджета из списка и нажмите «Добавить».
  4. В открывшемся окне настройки укажите параметры: название, объект, стиль, размеры и позицию.
  5. Сохраните — виджет появится на панели и сразу заработает.

Вкладки настройки виджета

  • Основная (main) — название, иконка, подпись, доступность.
  • Параметры (params) — объект, свойства, методы, логика конкретного типа виджета.
  • Дополнительно (advanced) — расширенные параметры (цвета, отображение, анимации).
  • Стиль — цвет, фон, прозрачность, рамки, шрифты.
  • Расположение (position) — позиция и размер на панели (x, y, ширина, высота), выравнивание.

Набор вкладок зависит от типа виджета: например, у таблицы есть вкладка «Колонки», у графика — «Графики», у группы — «Виджеты».

Работа с объектами Majordomo

Каждый управляющий виджет привязывается к объекту Majordomo: выберите объект и его свойство, а для команд — метод (Объект/Метод). Значения виджета обновляются в реальном времени через веб-сокеты.

  • Объект — имя объекта в системе (например kitchenLight).
  • Свойство — отслеживаемый параметр (например level, status).
  • Метод — команда, вызываемая при действии (например turnOn, setLevel).
  • Карта соответствий — в поле можно выбрать объект и метод раздельно («объект/метод»).
