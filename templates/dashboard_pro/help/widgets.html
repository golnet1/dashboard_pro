Виджеты

Виджет — это элемент панели, который отображает данные или управляет объектом. Ниже — общие правила; подробное описание каждого виджета — на отдельной странице: выберите подраздел в меню слева либо нажмите кнопку «Помощь» у виджета в окне добавления.

Добавление виджета

  1. Включите режим редактирования (карандаш внизу бокового меню).
  2. Нажмите кнопку «+» на нужной панели (или «Добавить виджет»).
  3. Выберите тип виджета из списка и нажмите «Добавить».
  4. Рядом с каждым виджетом есть кнопка — она открывает подраздел справки именно этого виджета.
  5. В открывшемся окне настройки укажите параметры: название, объект, стиль, размеры и позицию.
  6. Сохраните — виджет появится на панели и сразу заработает.

Вкладки настройки виджета

  • Основное (main) — название, иконка, специфические параметры типа виджета.
  • Дополнительно (advanced) — фон, цвета, скругление углов, контроль доступности, дополнительные параметры.
  • Специальные вкладки — зависят от типа: «Статусы», «Колонки», «Графики», «Слайды», «Варианты», «Виджеты», «Цвета».
  • Позиция — x, y, ширина, высота на панели.

Набор вкладок зависит от типа виджета: подробно для каждого типа — на его отдельной странице.

Общие настройки (у всех виджетов)

Большинство виджетов имеют одинаковый набор базовых настроек. В таблице ниже — что они означают:

НастройкаЧто делает
НазваниеЗаголовок виджета на панели. Если пусто — показывается название типа.
Тип иконкиИсточник иконки: Иконка (выбор из библиотеки), Свойство (класс иконки берётся из значения свойства объекта), URL (изображение-иконка по адресу).
ИконкаВыбор иконки из библиотеки (если тип иконки — «Иконка»).
Объект / Свойство иконкиОбъект и свойство, значение которого содержит класс иконки, например fas fa-lock (если тип иконки — «Свойство»).
URL иконкиАдрес изображения-иконки (если тип иконки — «URL»).
Фон виджетаСтиль фона карточки: «По умолчанию», «Изображение», «Заданный цвет», «Цвет из свойства».
ЦветЦвет фона (если фон — «Заданный цвет»).
URL изображенияИзображение-фон карточки (если фон — «Изображение»).
Объект / Свойство (цвет фона)Объект и свойство, значение которого — цвет в формате #RRGGBB (если фон — «Цвет из свойства»). Позволяет менять цвет карточки динамически.
Признак доступности + Таймаут (сек)Контроль связи с объектом. Объект и свойство, по которому проверяется «живость» устройства (например level или status). Если значение не приходит дольше таймаута — виджет блокируется и показывается приглушённым.
Скругление углов, pxСкругление углов карточки виджета. Поле есть на вкладке «Дополнительно». 0 или пусто — берётся значение «Общее скругление» из раздела Настройки → Настройки виджетов. Скругление применяется только при включённом там выключателе Закруглённые виджеты.

Поля из таблицы выше есть у большинства виджетов. Полный список полей каждого виджета — на его отдельной странице: там перечислены все поля, их ключи, типы и значения по умолчанию.

Работа с объектами Majordomo

Каждый управляющий виджет привязывается к объекту Majordomo: выберите объект и его свойство, а для команд — метод (Объект/Метод). Значения виджетов обновляются в реальном времени через веб-сокеты.

  • Объект — имя объекта в системе (например kitchenLight).
  • Свойство — отслеживаемый параметр (например level, status).
  • Метод — команда, вызываемая при действии (например turnOn, setLevel).
  • Карта соответствий — в поле можно выбрать объект и метод раздельно («объект/метод»).
